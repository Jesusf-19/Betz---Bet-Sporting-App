
  # Sports Betting App

  A full-stack sports betting web app built as a personal portfolio version of a collaborative software engineering class project.

  ## Project Note

  This project is inspired by an original group project completed for CPSC 491. This repository is my personal rebuilt version with cleaner structure, documentation, and portfolio-focused improvements.

  ## Team Credit

  Original project contributors will be credited here.

  ## Planned Features

    - View upcoming matches
    - Display betting odds
    - Place simulated bets
    - Track wallet balance
    - View bet history
    - Backend API with FastAPI
    - Frontend built with Next.js and TypeScript
    
  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
